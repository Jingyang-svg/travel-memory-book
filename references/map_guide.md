# 地图制作指南（可选模块）

纪念册封面可放一张「双城 / 多城手绘总览图」：按天着色的路线、每晚住宿、机场与离岛意向标记。
地图是**可选**的——纯城市行程、不想整理坐标时，在 `book_data.json` 里省略 `map` 字段即可，封面会自动用其它排版。

数据放在 `book_data.json` 的 `map`，结构：

```json
"map": {
  "cities": [ { ...城市1 }, { ...城市2 } ],
  "legend": [["c1","D1 · 10.03"], ["c2","D2 · 10.04"]]
}
```

## 城市对象字段

| 字段 | 必需 | 说明 |
|---|---|---|
| `id` | 是 | 城市短 id，如 `"bk"` |
| `tab` | 是 | 标签页文字，如 `"曼谷 Bangkok"` |
| `sea` | 是 | 是否海滨城市（决定底色与正方形比例） |
| `view` | 是 | 画布与经纬度范围，见下 |
| `points` | 是 | 点位数组 `{id,n,lat,lng,kind}` |
| `edge` | 视情况 | 超出视野、意向化放在画布边缘的点 `{id:[x,y]}` |
| `lines` | 是 | 按天路线 `{c,ids,dash?}` |
| `fly` | 视情况 | 飞行 / 船的意向标记 |
| `labelAdj` | 推荐 | 标签微调 `{id:[dx,dy,anchor]}`，防遮挡 |
| `minor` | 可选 | 只画点、不标文字的次要点位 id 数组 |
| `river` | 可选 | 河流 `[[lat,lng],...]`（内陆城市） |
| `polygons` | 可选 | 陆地轮廓 `[[[lng,lat],...]]`（海滨城市，成本高可省） |
| `islets` | 可选 | 离岛椭圆 `[{id,at:[x,y],rx,ry}]`，`id` 关联点位并跳过圆点标记 |

`kind` 取值：`"airport"` 机场（飞机方块）、`"hotel"` 住宿（旗帜）、`"sight"` 景点（圆点）。

## 制作步骤

1. **列点位、取坐标准确**：每个点在 Google Maps 右键查经纬度（或长按钉子），填入
   `{id,n,lat,lng,kind}`。坐标错了点会错位，务必逐一核对。
2. **定 view**：`{W,H,pad,latMin,latMax,lngMin,lngMax}`，让**主要市区点**铺满画布。
   - 内陆城市常用宽矮画布（如 `W:1000,H:467`）；海滨城市用正方形（`W:900,H:900`）。
   - 经纬度范围框住主要点，`pad` 留边距。
3. **大跨度意向化**：远机场、离岛、跨城点**不要按真实比例**塞进视野——把它们放进 `edge`，
   手动给一个画布边缘坐标（如 `"BKK":[866,400]`），路线用虚线（`"dash":[6,7]`）连接。
   这样版面留给真正的市区行程，避免「下方全挤在一起」。
4. **画 lines**：每天一种路线色。
   `"c":"var(--c1)"`，`ids` 按访问顺序；当天实际走的用实线，转场 / 意向用 `dash`。
5. **加 fly**：航班 / 船的虚线 + 图标，`{at:[x,y],txt,id,ic}`；
   `ic:"boat"` 用于离岛船程（可加 `"boat":true`），其余用 `"plane"`。
6. **海滨城市**：`sea:true`；想画陆地轮廓就提供 `polygons`（`[lng,lat]` 环），
   离岛用 `islets` 椭圆并关联点位 id。嫌麻烦可省略 `polygons`，仅用海色底 + 点位。
7. **调标签**：截图后凡有重叠 / 压线，用 `labelAdj` 给该点 `[dx,dy,anchor]`
   （`anchor` 为 `"start"/"middle"/"end"`）；次要点放进 `minor` 只画点不标字。

## 片段示例

```json
{
  "id": "bk", "tab": "曼谷 Bangkok", "sea": false,
  "view": {"W":1000,"H":467,"pad":30,"latMin":13.735,"latMax":13.767,"lngMin":100.483,"lngMax":100.559},
  "edge": {"DMK":[872,58], "BKK":[866,400]},
  "points": [
    {"id":"debtida","n":"班德提达民宿","lat":13.7515,"lng":100.5033,"kind":"hotel"},
    {"id":"grandpalace","n":"大皇宫 / 玉佛寺","lat":13.7501,"lng":100.4928,"kind":"sight"},
    {"id":"BKK","n":"素万那普机场","lat":13.6900,"lng":100.7501,"kind":"airport"}
  ],
  "river": [[13.766,100.494],[13.752,100.4915],[13.736,100.507]],
  "lines": [
    {"c":"var(--c1)","ids":["debtida","grandpalace","watpho","watarun","khaosan","debtida"]},
    {"c":"var(--c2)","ids":["yaowarat","BKK"],"dash":[6,7]}
  ],
  "fly": [{"at":[948,350],"txt":"10.3 北京飞来","id":"BKK","ic":"plane"}],
  "minor": [],
  "labelAdj": {"grandpalace":[12,4,"start"]}
}
```

## 校验

- 构建后封面切到每个城市标签逐一截图：点位落在正确位置、标签互不遮挡、无横向溢出。
- 控制台不应出现 `<path> ... Expected moveto` 之类错误（引擎生成的路径都以 `M` 开头）。
- 海滨城市确认切到该城市时地图为正方形（`sea:true` 触发，无裁剪）。
