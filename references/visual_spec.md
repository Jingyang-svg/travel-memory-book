# 视觉规范

**定位：胶片摄影杂志 / 旅行手账。** 米纸底色、墨色文字、衬线大标题、按天着色的手绘路线，整体像一本印出来的摄影集，而不是攻略 App。微调模板时必须守住这套 token，不引入风格外的颜色与字体。

## 字体

- 中文大标题：**Noto Serif SC**（900）。
- 中文正文：**Noto Sans SC**。
- 英文展示：**DM Serif Display**。
- 英文正文 / 斜体：**Spectral**。

字体**自托管**（miaoda.feishu.cn 资源），不直连 Google Fonts，保证离线 / 内网可打开。

## 版式与照片网格

- 内容居中、单栏阅读；桌面端封面左右并排，手机端单栏。
- 每日照片为 **6 列网格**，跨度由构建器按图片方向自动决定（无需手填）：
  - 竖图占 2 列；横图占 4 列；
  - 当天**最后一张若为横图则占满 6 列**收尾。
- 每天默认**折叠**，折叠条显示头图 + 日序 / 日期 / 主题；右侧有 D1–DN 快速导航。
- 四个专栏穿插：旅途最佳大图、纪念数据 stats、金句、时间胶囊，最后谢幕。

## 质感与动效

- 纸张感：分层米底 + 发丝线边框，圆角很小（3–6px），不用重阴影、不用毛玻璃。
- 地图为手绘 SVG：平滑曲线、圆点 / 旗帜标记、指南针，远距离用虚线 + 图标「意向化」表达。
- 动效克制：仅展开 / 折叠等响应动作，不做全站淡入、不飘粒子。
- 尊重 `prefers-reduced-motion`。

## 微调原则

- 只在确有必要时改 `assets/template.html`；改颜色 / 字号优先用上述 token，不硬编码新值。
- 一次只让一个元素成为视觉重点，其余保持安静。
- 改完必须重新 build 并在**桌面 + 手机**双端截图复看（见 [workflow.md](workflow.md)）。
