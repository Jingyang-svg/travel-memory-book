# 数据结构规范（book_data.json）

每趟旅行只产出一份 `book_data.json`，连同照片根目录交给 `build_book.py`。
所有照片 / 音乐 / couple 的路径都**相对照片根目录**；构建器会压缩图片、转码音乐并把整份数据注入模板。

## 顶层结构

```json
{
  "meta":   { ... },
  "days":   [ ... ],
  "best":   ["旅途最佳.jpg", "说明"],
  "stats":  [ ... ],
  "quotes": [ ... ],
  "capsule":{ "q": "下一站，我们想去……", "a": "印尼 · 巴厘岛" },
  "ending": "谢幕一段……",
  "map":    { ... }
}
```

`map` 可省略（见 [map_guide.md](map_guide.md)）；`best` 可省略。

## meta

| 字段 | 含义 | 示例 |
|---|---|---|
| `en` | 英文大标题 | `"Bangkok × Phuket"` |
| `title` | 中文大标题 | `"曼谷 × 普吉"` |
| `range` | 日期区间 | `"2026.10.03 – 10.08"` |
| `days` | 天数说法 | `"6 天 5 晚"` |
| `authors` | 署名 | `"YY & BB"` |
| `kicker` | 可选，封面眉标；省略用默认 `"A Travel Memoir · 旅行纪念册"` | `"A Travel Memoir"` |
| `music` | 音乐源文件名（相对照片根），无则 `null` | `"the fate of Ophelia.m4a"` |
| `couple` | couple 装饰图源文件名，无则 `null` | `"couple.png"` |

## days[] 元素

| 字段 | 含义 |
|---|---|
| `d` | 日序，`"D1"` |
| `date` | 日期，`"10.03"` |
| `week` | 星期，`"周五"` |
| `city` | 当天所在城市，`"曼谷"` |
| `title` | 当日主题（短语），如 `"金色皇宫与泰拳之夜"` |
| `places` | 当天地点串，用 ` · ` 分隔 |
| `story` | 杂志式一段：第一人称、有具体细节与情绪，3–6 句 |
| `bits` | 「碎片小事」短句数组，每条一句，建议 5–10 条 |
| `cover` | `[相对路径, 说明]`，当日折叠条头图 |
| `photos` | `[[相对路径, 说明], ...]`，当日照片网格 |

示例：

```json
{
  "d": "D1", "date": "10.03", "week": "周五", "city": "曼谷",
  "title": "金色皇宫与泰拳之夜",
  "places": "素万那普机场 · 大皇宫玉佛寺 · 湄南河摆渡 · 郑王庙 · 泰拳 · 考山路",
  "story": "飞行六小时，曼谷用一阵潮热和老板娘的笑脸接住了我们。年近八十的讲解奶奶一口气讲了两个多小时……",
  "bits": ["讲解奶奶快 80 岁，讲了两个多小时", "泰服裤子居然是开裆的"],
  "cover": ["1/大皇宫.jpg", "大皇宫的金顶"],
  "photos": [["1/启程.jpg", "落地"], ["1/郑王庙写真1.jpg", "郑王庙写真"]]
}
```

## best / stats / quotes / capsule / ending

- **best**：`[路径, 说明]`，全页最有代表性的一张，用于「旅途最佳」专栏大图。
- **stats**：`[{ "n": 数字, "label": 标签, "wide": 可选 }]`，纪念数据。`wide:true` 占整行。
  例：`{"n":6,"label":"天"}`、`{"n":29,"label":"处风景"}`、`{"n":4,"label":"次出海"}`。
  数字按真实内容统计，不编造。
- **quotes**：`[{ "q": 金句, "who": 可选署名 }]`。可放多条；`who` 省略不署名。
- **capsule**：`{ "q": 提问, "a": 回答 }`，「时间胶囊」专栏，通常写下一站目的地。
- **ending**：谢幕一段，收束全程、留有余味。

## 写作口径

- 全程**第一人称、口语、有温度**，像写给朋友看，不像攻略说明书。
- 保留用户口述里的具体人名、细节、笑点与狼狈（如「目的地又搞错了」「上吐下泻」）。
- 用户已确认的金句 / 胶囊答案 / 署名**逐字保留**，不自行改写。
- 数字（天数、景点数、出海次数）从实际行程与照片统计，宁可少写不虚构。
- 不写任何证件、票号、确认号、房间号、电话（公开页，见 [workflow.md](workflow.md) 隐私红线）。
