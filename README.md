# travel-memory-book · 旅行纪念册

> 回来后的「印出来的摄影杂志」—— 一本可分享链接、慢慢翻看的旅行回忆。

## ✨ 亮点

- **零排版**：照片按 `1/2/3…` 天放进文件夹 + 一段口语化日记，自动成书
- **胶片杂志风**：封面手绘总览图、最佳全页大图、金句、时间胶囊、谢幕页
- **逐日照片墙**：每天折叠展开，16–18 张精挑细选
- **背景音乐**：循环播放、可一键关闭（首次交互后自动播）
- **滑动看片**：点开照片可手指左右滑，也有箭头按钮
- **纪念数据**：天数、景点数、出海次数自动统计
- **手机优先**：竖屏翻着看，桌面端同样美观

## 📦 你只需提供

| 给什么 | 说明 |
|---|---|
| 照片文件夹 | `1/` `2/` `3/` … 子目录名 = 第几天，文件名随意 |
| 每日回忆 | 口语化叙述，保留人名、细节、笑点与狼狈 |
| （可选）最佳一张 | 根目录放旅途最佳，用作封面 / 全页大图 |

## 📱 产出效果

- 封面：标题 + 金句 + 手绘小人 + 总览地图（可选）
- 每日：折叠照片墙 + 当天故事
- 中场：最佳大图 + 纪念数据
- 结尾：时间胶囊 + 金句谢幕

## 🛠 技术特点

- **数据 / 引擎分离**：模板、构建器、地图、灯箱引擎固定，每趟只换一份 `book_data.json` + 照片
- 响应式，桌面 + 手机双端自检
- 字体完全离线

## English

> A printed-photo-magazine memory book after the trip — a shareable link you revisit.

- **Zero layout work**: drop photos into day folders (`1/ 2/ 3/`) + a casual diary line per day, it builds itself
- **Film-magazine style**: hand-drawn cover map, full-page best shot, quote, time capsule, closing page
- **Per-day wall**: collapsible, 16–18 curated photos a day
- **Background music**: looping with a mute button (starts on first tap)
- **Swipeable lightbox**: finger-swipe or arrow keys to browse
- **Trip stats**: days, sights visited, boat trips, auto-counted
- **Mobile-first**: built for scrolling on the phone
